# Security, privacy and ethical use

1. AI only extracts evidence from CV text, candidate-answer transcripts and technical code/test output. AI output never authorizes hiring decisions. CV/video/coding evidence parent graphs pause at persisted recruiter-only LangGraph `interrupt` checkpoints; the only way to advance is an authorized recruiter action with documented rationale.
2. Organization isolation: recruiter membership and active organization ID are validated on job/application, team comment, PDF, challenge and analytics endpoints. Candidate files and video are accessed only through authenticated endpoints. A candidate may access only their own applications.
3. Access tokens currently live in browser `localStorage`; improve this in production (HttpOnly cookie strategy, CSRF protections, refresh rotation, MFA/SSO). Registration creates a private company workspace. Invitation codes are secrets; rotate as needed.
4. Media uploads are size- and signature-checked; no executable candidate code is evaluated on the API host. Remote Judge0 is HTTPS-only, configured by the operator, does not follow redirects, and enforces CPU/time/memory caps. Add virus scanning and object storage for production.
5. Webcam/iris monitoring is **optional, local, temporary and not uploaded**. No facial recognition, gaze scoring, emotion inference, candidate rankings or automated rejection. Candidate can dismiss or turn off a reminder. External voice/audio upload is separately opt-in and requires recording consent.
6. SMTP interview invitations require configured credentials and candidate email opt-in. In-app notifications are locally stored. Reminders are deduplicated by audit row and only function while the backend process is running; replace the scheduler before running multiple workers.
7. Personal-data export and per-application deletion cover current database rows, recordings, notes and LangGraph checkpoints. File-system backup copies, vacuumed SQLite pages, export copies, AI provider retention and legal holds must be handled outside the app. Record formal retention and erasure procedures before processing actual candidate information.
8. Known missing controls for public production: hardened HTTPS reverse proxy, persistent rate limits, secret management, audit tamper protection, Alembic migrations, encryption at rest, backups/restore exercises, password reset and verification, rich permissions, file malware scanning, OWASP penetration testing, consent/version records, bias studies, legal approval, dedicated workers and data residency controls.

**Never treat a candidate looking away from the webcam as proof of dishonesty, attention problems or cheating. Never use facial tracking data in hiring decisions.**
